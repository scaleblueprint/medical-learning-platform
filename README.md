# Medical Learning Lab

An AmberTheory ideation prototype for intuitive, competency-aware medical learning.

## Prototype scope
- MBBS learning map
- First Professional subject shell
- Physiology showcase
- Cardiovascular learning path with 5 lessons
- Experience → Predict → Explore → Understand → Connect → Apply → Check learning model
- Interactive cardiac-output model
- Faculty-review-required content governance
- Student/intern/faculty feedback UI

## Run
```bash
npm install
npm run dev
```

## Validate
```bash
npm run validate:release
```

## Medical-content boundary
This prototype is for education design exploration. It is not intended for diagnosis, treatment, or patient-specific medical advice. Curriculum and medical-content mappings must be verified by qualified medical faculty before being represented as authoritative.
