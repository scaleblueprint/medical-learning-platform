# Medical Visual Learning Standard

This standard applies to every medical lesson added to the platform. The goal is not to reproduce textbook pages. The goal is to reduce cognitive overload while preserving medically meaningful relationships.

## Student need
Medical learners often meet a concept through dense prose, crowded labelled figures and several new terms at once. The platform should therefore separate **seeing the relationship**, **naming it medically**, **studying the detail** and **recalling it later**.

## Required visual-memory sequence
Every reviewed prototype lesson should provide, where appropriate:

1. **Experience** — familiar physiological or everyday situation.
2. **Predict** — learner commits before the answer is revealed.
3. **Explore** — concept-specific interactive model.
4. **Understand** — concise formal explanation.
5. **See it** — one simplified concept diagram showing the central relationship.
6. **Map it** — analogy mapped explicitly to the medical mechanism, including where the analogy stops.
7. **Remember it** — one memory rule plus a small set of cues.
8. **Redraw it** — a 20-second sketch instruction focused on relationships rather than artistic accuracy.
9. **Correct it** — common misconceptions shown beside corrections.
10. **Say it** — viva quick answer: one-line response first, then expandable supporting points.
11. **Study in depth** — mechanisms, terminology, equations/relationships, values, references and broader detail.

The visual-memory layer sits after the learner has predicted and explored the idea so that the diagram reinforces reasoning rather than giving away the prediction.

## Diagram rules
- One diagram should answer one main learning question.
- Prefer a few large labels over many small labels.
- Use progressive or separate diagrams instead of reproducing a dense textbook plate.
- Keep shapes and visual grammar consistent across systems.
- Use arrows only when direction, sequence, causality or feedback is meaningful.
- Do not use decorative anatomy images when a simplified relationship diagram teaches the concept better.
- Do not imply anatomical precision when a diagram is intentionally schematic; label it as a simplified concept diagram.
- Color must never be the only way to distinguish meaning.
- Diagrams must remain legible on tablet/mobile without requiring tiny text.

## Analogy rules
- The analogy must explain a specific relationship, not merely make the lesson entertaining.
- Always provide the medical mapping directly beside the analogy.
- Always state where the analogy stops or becomes misleading.
- Avoid analogies that introduce more concepts than they remove.

## Memory design
A memory anchor should contain:
- one short rule or relationship;
- three to five cues maximum;
- terminology that matches the formal lesson;
- no unsupported mnemonic claims.

A redraw prompt should be simple enough to reproduce from memory in roughly 20 seconds. The learning objective is retrieval of structure and relationships, not drawing quality.

## Viva design
Start with a defensible one-line answer. Expand only when the learner opens the supporting points. This mirrors how a student can begin a viva answer clearly and then elaborate if asked.

## Asset and copyright rule
Prefer original SVG/CSS diagrams and purpose-built educational illustrations. Do not copy or redraw proprietary textbook figures closely. If an external image is ever used, its licensing and provenance must be recorded and the image must materially improve learning.

## Medical governance
All diagrams, labels, analogies, memory anchors, viva answers and corrections remain `faculty-review-required` until medically reviewed. A visually intuitive diagram is not evidence of medical correctness.

## Current cardiovascular implementation
The prototype currently uses five original visual models:
- circulation loop / two pumps in series;
- four-state cardiac-cycle wheel;
- cardiac-output equation and stroke-volume determinants;
- pressure-flow-resistance pipe model;
- baroreflex negative-feedback loop.

Future respiratory, renal, nervous and endocrine lessons should use the same design principles without copying cardiovascular-specific visuals.
